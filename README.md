# NetAcademy

An offline computer networking course with animated diagrams. It covers:

- **Fundamentals:** OSI, TCP/UDP, IPv4, subnetting, IPv6
- **Cabling & racks:** cable types, T568A/B termination, rack layout, structured cabling
- **Cisco CCNA topics:** IOS, switching, VLANs, STP, EtherChannel, wireless, routing, OSPF, DHCP, DNS, NAT, ACLs
- **Windows Server & Active Directory:** AD DS, DNS, Kerberos, Group Policy, groups, replication
- **Hands-on labs:** step-by-step setup guides, from Packet Tracer and Windows Server VMs to crimping cables and building a rack

Each lesson has step-by-step animations with optional narration and sound, quizzes, and a commands block. There is also a subnet calculator, a CLI reference and a practice exam. Your progress is saved in your browser.

## Use it

- **Online:** open the GitHub Pages site for this repository.
- **Offline:** download or clone the repository and open `index.html` in any modern browser. It needs no server, no build step and no internet connection.

## Add your own videos or audio

Put your files in the `media/` folder and list them in `media/media.js`. The examples in that file show the format.
